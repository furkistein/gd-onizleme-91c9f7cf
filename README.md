# Gelinler Dağı sayfa önerisi (önizleme)

Müşteriye gösterilecek taslak sayfalar. Arama motorlarına kapalı (robots.txt + her sayfada noindex).
Sayfalarda "Önizleme taslağı" şeridi ve sarı işaretli yer tutucular bulunur; fiyat yoktur.

- index.html: sayfa listesi
- bayilik.html: bayilik ve toptan (TR)
- ihracat_en.html / ihracat_ar.html: ihracat (EN, AR)

Yayın (YALNIZ Furkan onaylarsa): bu klasörün içeriği yeni, gizli olmayan ama adı tahmin edilmesi zor bir depoya
(örn. gd-onizleme-<rastgele>) konur; Settings > Pages > main / root. Adres dışarıya açık olur, bu yüzden
müşteriye gitmeyecek bilgi (yer tutucu notları dışında) içermediğini kontrol edin.
Kaynak: ../_kaynak/derle.py, yeniden derlemek için çalıştırıp dosyaları buraya kopyalayın.
